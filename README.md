# Market Pro - Sistema de Facturación

Aplicación de escritorio desarrollada con Electron, React y FastAPI para gestión de:

* Ventas
* Inventario
* Productos
* Facturación
* Reportes

Próximamente video demo.

## Tecnologías

* Electron
* React
* Javascript
* FastAPI
* SQLite/PostgreSQL
