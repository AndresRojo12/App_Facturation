## 🎓 Conceptos Clave

| Concepto | Explicación |
|----------|-------------|
| **SaleForm** | Componente principal que gestiona búsqueda y carrito |
| **SaleCart** | Componente que muestra el carrito y totales |
| **CartItem** | Un producto en el carrito con cantidad y subtotal |
| **Stock** | Cantidad disponible de un producto |
| **Subtotal** | Precio × Cantidad para un producto |
| **Total** | Suma de todos los subtotales |
| **Venta** | Cuando finalizas el carrito |
